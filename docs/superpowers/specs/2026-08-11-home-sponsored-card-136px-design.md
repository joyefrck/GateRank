# 首页广告卡 136px 紧凑化设计

## 背景

首页商业合作广告已移动到右侧栏，并在上一轮调整中隐藏价格、将占用广告卡压缩到约 168px。当前目标是在不改变广告数据、链接和追踪逻辑的前提下，继续降低卡片高度，使其与左侧 GateRank 排行榜的紧凑操作区保持一致。

## 视觉主张

广告卡采用克制、紧凑的白色信息面板：机场名称和活动标题承担主要信息层级，操作按钮沿用排行榜的小尺寸视觉语言，移除会分散注意力的机场首字图标和标签行，避免右栏抢夺左侧排行榜的视觉重心。

## 内容层级

占用广告卡从上到下只展示：

1. 左对齐的机场名称和观察天数。
2. 单行活动标题，超出宽度时省略。
3. 横向排列的“查看报告”和“官网”按钮。

以下内容仅从首页广告卡隐藏，不删除数据字段，也不改变后台配置或接口：

- 机场标签。
- 优惠码标签。
- 月付价格。
- 机场名称左侧的首字图标。

## 尺寸与布局

- 占用广告卡目标最小高度为 `136px`，相较当前 `168px` 减少 `32px`。
- 卡片继续使用单列布局，每行一个广告位。
- 卡片圆角维持 `18px`，使用现有浅边框、轻阴影和白色至浅灰背景。
- 机场名称区不显示首字图标，也不使用其他装饰图形替代；名称和观察天数从卡片内容起点直接左对齐。
- 卡片内边距和区块间距同步收紧，但名称、观察天数和活动标题不得拥挤或遮挡。
- 活动标题限制为单行省略，避免长文案把卡片撑高。
- 操作区保留细分隔线。
- 两个按钮继续等宽横向排列：主按钮视觉高度约 `32px`，次按钮约 `30px`，沿用排行榜按钮的圆角、字号和主次样式。
- 空广告位同步压缩到不高于占用广告卡，并保持招商文案和入口清晰。

## 交互与可访问性

- “查看报告”仍为近黑色主操作，“官网”仍为白色描边次操作。
- 保留现有 hover、focus-visible 和 reduced-motion 行为。
- 保留报告链接的可抓取语义。
- 保留官网链接的 `nofollow sponsored noopener noreferrer` 属性和广告点击追踪。
- 不改变广告曝光追踪、campaign ID、airport ID、placement 或去重键。

## React 与 SSR 一致性

React 首页和服务端渲染首页必须同步：

- 不渲染标签与优惠码标签。
- 不渲染价格。
- 不渲染机场首字图标或替代图形，机场名称与观察天数直接左对齐。
- 保留机场名称、观察天数、活动标题和两个链接。
- 使用相同的 136px 目标高度和紧凑按钮节奏。
- 空广告位采用对应的紧凑尺寸。

## 验收标准

- 桌面浏览器中，占用广告卡高度约为 `136px`，同列卡片节奏一致且无内容溢出。
- 移动端无横向溢出；名称和活动标题过长时正确省略。
- 首页广告卡中不存在机场标签、优惠码标签和价格文本。
- 首页占用广告卡中不存在机场首字图标或替代装饰图形。
- 机场名称和观察天数与卡片左侧内容边界对齐，右栏视觉权重弱于左侧排行榜。
- 两个按钮的视觉尺寸与左侧 GateRank 排行榜操作按钮一致。
- 报告链接、官网链接、广告属性、点击追踪和曝光追踪全部保留。
- React 与 SSR 的结构、字段可见性和尺寸表现一致。
- 相关前端静态契约测试、公共页面路由测试、TypeScript 检查和生产构建通过。

## 非目标

- 不修改广告数据模型、接口或后台表单。
- 不修改排行榜卡片或排行榜按钮本身。
- 不修改商业合作专区标题、招商入口或广告位排序。
- 不修改机场详情页、优惠页或其他页面上的标签与价格展示。
