# 说明节点过滤规则收紧设计

## 背景

大象网络的订阅快照包含 5 个名称为“韩国-标准套餐01”至“韩国-标准套餐05”的真实韩国节点，地区字段均为 `KR`。当前统一说明节点过滤器只要节点名称包含“套餐”就排除，导致报告页地区统计漏掉韩国，并可能影响未配置人工节点偏好时的性能采集节点选择。

## 设计

- 保留统一的 `isInformationalNodeName` 入口，让报告、性能采集和网络覆盖继续使用同一套判断。
- 删除泛化的独立“套餐”关键词，改为识别“套餐到期”这一明确说明短语。
- 继续识别“剩余流量”“流量”“到期”“官网”“公告”等既有说明行。
- 正常节点名中的“套餐”不再触发过滤，例如“韩国-标准套餐01”。
- 不针对韩国或 `KR` 做特殊放行，确保其他地区的同类正常节点名称也得到一致处理。

## 数据流

订阅快照节点进入统一过滤器后，真实节点继续流向报告地区聚合、性能采集候选节点和网络覆盖地区识别；说明行仍在这些入口被排除。该修复不修改数据库内容，也不需要重采订阅快照。

## 验证

- 报告视图回归：`韩国-标准套餐01` 计入韩国节点覆盖，“剩余流量”说明行仍不计入英国。
- 性能调度回归：无人工偏好时，韩国套餐节点可进入自动选择，说明行不可进入。
- 网络覆盖分类回归：韩国套餐节点识别为 `KR`，套餐到期说明行仍识别为未知地区。
- 运行后端定向测试、全量后端测试、服务端类型检查、前端类型检查、构建和差异检查。
