# 报告详情页移除网络覆盖快照设计

## 目标

从 GateRank 公开报告详情页移除“网络覆盖快照”整块信息，减少与“网络覆盖（N）”评分卡重复的展示内容。

## 范围

- React 报告详情页不再渲染网络覆盖快照。
- SSR 报告详情页同步移除相同区块，保持首屏 HTML 与客户端一致。
- 保留评分拆解中的“网络覆盖（N）”卡片和五轴雷达图。
- 保留公开接口中的 `network_coverage` 字段，避免破坏现有消费者。
- 保留后台 N Tab、采集运行记录和全部评分计算逻辑。

## 页面结构

评分拆解卡片结束后直接进入“核心监测指标”，不增加折叠入口、提示文本或替代卡片。

## 验收

- v2 React 与 SSR 报告均不包含“网络覆盖快照”、Healthy / Detected、UNKNOWN、unsupported 等快照明细。
- v2 报告仍显示 N 分卡片和五维雷达。
- v1 四维报告行为不变。
- 类型检查、相关报告测试和生产构建通过。
