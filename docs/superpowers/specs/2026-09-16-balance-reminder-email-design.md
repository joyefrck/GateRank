# 余额明细邮件催促

在机场管理的余额明细弹窗中，余额旁增加「邮件催促」描边按钮。点击直接发送，显示发送中、成功或失败反馈。发送成功后短暂禁用，后端按机场限制一分钟一次，失败允许重试。

采用独立 HTML 邮件模板，复用现有 SMTP 发送配置。邮件包含机场名称、后端读取的当前钱包余额、余额不足对公开评分和排序的影响，以及「登录后台充值」按钮与完整可点击登录地址。地址复用 `buildPortalLoginUrl` 的 `/portal` 入口。HTML 使用内联样式、表格布局和动态内容转义，同时附纯文本兼容内容。

收件人遵循已有人工邮件操作：优先机场联系邮箱，缺失时使用关联申请人账号邮箱。没有机场、钱包、邮箱或可用 SMTP 时返回明确错误。接口位于已有管理员鉴权路由下，成功发送后记录审计。不调整余额、排名规则或自动通知任务。

验证覆盖实际发送参数、HTML 转义与链接、SMTP 错误、收件人回退、缺失资料、重复请求；检查桌面和手机弹窗及邮件预览，完成前后端类型检查和生产构建。测试使用模拟邮件服务。
