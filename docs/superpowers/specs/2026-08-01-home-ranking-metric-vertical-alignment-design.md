# GateRank 首页排行榜关键列垂直居中设计

## 目标

将首页桌面排行榜中排名、GateRank 分、月付价格和观察时长四列的内容在每一行内上下居中，修复短内容相对机场名称、标签和操作按钮明显偏上的视觉问题。

## 已确认范围

- 排名徽章单元格上下居中。
- GateRank 分及“对比昨天”组合上下居中。
- 月付价格及“起 / 月付”组合上下居中。
- 观察时长上下居中。
- 机场名称、机场图标、标签和操作按钮保持现有布局。
- 表头、列宽、行高、字体、颜色、数据与交互保持不变。
- 移动端排行榜卡片不受影响。

## 实现方案

React 桌面表格在 `RankingTableRow` 的四个目标 `<td>` 上增加 Tailwind `align-middle`。垂直对齐由表格单元格自身承担，不增加固定高度，也不改变内部内容结构。

SSR 首页排行榜在 `.home-v3-table-wrap td` 的专用样式中增加 `vertical-align: middle`，确保服务端首屏与 React 接管后的垂直对齐方向一致。SSR 表格结构比 React 表格紧凑，因此该专用规则覆盖 SSR 排行榜所有正文单元格，不影响其它公共页面表格。

不采用整行 React 垂直居中，因为机场信息列和操作列当前依靠自身内容高度获得合理位置；扩大作用范围会带来不必要的视觉变化。不采用定高 Flex 包装，因为它会把简单的表格对齐问题变成行高耦合。
