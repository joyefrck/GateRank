# 优惠详情页冗余操作移除设计

## 目标

机场优惠详情页已经是“优惠详情”的目标页面，卡片底部不再显示会跳回当前页面的“优惠详情”按钮；优惠活动总览页仍保留该入口。

## 方案

- 为共享 `DealCard` 增加显式的可选属性，用于控制是否渲染“优惠详情”操作，默认保持显示。
- `DealsPage` 不传该属性，继续使用黑色主操作进入机场优惠详情页。
- `DealDetailPage` 显式关闭该操作，避免依赖当前 URL、尾斜杠或查询参数推断页面类型。
- 详情页操作轨只保留“查看测评”和“官网”，两项等分且保持 40px 触控高度；官网不存在时，“查看测评”独占整行。
- 保留优惠码复制、测评路由、官网外链属性、点击统计和曝光统计。

## 视觉层级

详情页的主要任务是阅读并复制优惠码，因此不再人为创建一个指向自身的深色主按钮。剩余两个跨页面操作使用首页风格的克制文字操作和细分隔线，避免与优惠码形成竞争。

## 测试与验收

- 源码回归测试确认详情页关闭该操作、总览页继续保留默认行为。
- 浏览器验证详情页桌面端和 375px 移动端均只显示“查看测评 / 官网”，且无横向溢出。
- 运行 TypeScript 检查和生产构建，提交对应构建产物。
