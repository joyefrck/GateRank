# 优惠详情页风险区重复按钮移除设计

## 目标

移除机场优惠详情页“购买前先核对服务能力与风险”区域底部重复出现的“查看测评报告”和“访问官网”按钮，只保留该区域的机场状态、支付方式和机场简介。

## 实现

- 直接删除 `DealDetailPage` 风险信息区的 CTA 容器及两个链接，不使用 CSS 隐藏。
- 清理仅由这组链接使用的 `ExternalLink` 图标、`normalizeExternalHref` 导入和 `websiteHref` 变量。
- 保留页面面包屑使用的 `navigate`，并保留上方优惠卡片中的“查看测评 / 官网”操作及其官网点击统计。
- 不改变接口数据、SEO、结构化数据、优惠码复制或其他页面。

## 验收

- 源码测试确认风险区标题和三项信息仍在，但该区域后的重复 CTA 不再存在。
- 浏览器确认桌面端和 375px 移动端风险信息区在简介卡片后直接结束，无按钮和多余空白。
- 运行 TypeScript 检查、聚焦测试和生产构建。
