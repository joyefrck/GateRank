# 官网风险异地复核

用户已要求修复中心点误报，并允许使用上海、广州。保留正常中心检测；中心返回服务错误或网络失败时，通过现有大陆探针身份派发独立官网任务。官网任务使用独立表、独立轻量定时服务，不等待性能/覆盖任务完成，也不暴露新入站端口。

两地并行执行与中心相同的 DNS 公网校验、地址固定、重定向逐跳校验、TLS 和 HTTP 检测，最多 30 秒。复用既有 bearer 认证，仅允许对应探针领取和提交自己的未过期任务。回传只包含白名单诊断字段，隐藏查询参数、片段与响应正文。

任一地区明确取得 HTTP 2xx 可消除单点网页异常；保留全部地点的原始诊断。实测发现上海、广州程序请求也会遭遇418。对于VeilX响应，必须同时匹配服务头、安全验证标题与/_waf/资源，标记为网站安全验证，源站页面未确认，不把普通418一概放行。此状态与既有Cloudflare验证一致，domain_ok=true但不声称源站正常。没有正常页面或已确认的WAF证据时，只有两地均明确失败才采用中心失败；异地未完成或执行异常时不写入新的失败指标。历史证据不可改写，采用结果通过现有事务持久化。管理页展示选用地点以及每个地点的状态。

上线需备份、发布同一提交的 API/Web、安装两台探针的独立官网 worker，重新检测机场 42 并验证持久化、实际页面和原有性能/覆盖 worker。没有生产连接时不得声称已上线。
