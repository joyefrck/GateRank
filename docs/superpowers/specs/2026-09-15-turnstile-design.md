# GateRank 登录与入驻申请真人校验

用户授权在现有 Cloudflare 账户配置 Turnstile，并对 `/portal`、`/apply` 最小化接入。

采用托管模式，每个表单在操作按钮旁新增一个浅色、自适应宽度组件。保留原表单、成功页、SEO 和既有登录流程。第三方登录仅在发起 X/Telegram 流程时校验，回调和轮询继续验证原有一次性凭据。

后端调用固定 Siteverify 地址，校验 success、hostname 和 action；缺失、超长、过期、重复、错误场景和网络故障拒绝请求。申请校验位于数据库、邮件和通知操作之前。新增申请 IP 与邮箱组合限流，保留登录限流。前端失败可重试且保留输入；令牌使用后重置。

前端通过 no-store 公共配置接口读取 site key，secret 仅通过后端环境变量加载。生产默认要求校验；本地显式关闭或使用官方测试密钥。域名限定 gate-rank.com 和 www.gate-rank.com，不启用预清除。

验收：服务单测覆盖失败关闭、域名/场景隔离；路由测试证明拒绝时业务服务未调用；已有登录和申请回归；类型检查、独立目录构建、桌面与手机宽度浏览器检查。生产生效需配置 secret 并同步发布 Web/API。
