# IP 检测页移除 VPN 广告设计

## 目标

从 GateRank 的 IP 检测页完整移除 ElephantRoute VPN 推广横幅，包括推广文案、按钮和外链，不保留空白占位。

## 变更范围

- 删除 `IpCheckPage` 中的 VPN 横幅渲染与组件。
- 删除中英文翻译对象中仅供该广告使用的字段。
- 清理广告专用图标导入。
- 保持 IP 查询、地图、结果详情、复制功能、数据源和隐私说明不变。

## 验证

- 添加源码约束测试，防止页面重新出现横幅组件、ElephantRoute 域名或广告翻译字段。
- 运行后端测试、前端类型检查和生产构建。
- 发布后在真实生产页面确认广告消失，同时地图和查询结果仍正常显示。
