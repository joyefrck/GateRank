# GateRank 首页商业合作卡片广告标记与评分移除设计

## 目标

从首页“商业合作专区”的每张已投放卡片中移除右上角广告标记和价格区右侧的评分徽章，使卡片只保留机场名称、观察天数、优惠信息、标签、起步月付、报告入口和官网入口。

## 已确认范围

- React 首页卡片不再显示 `AD 广告`。
- React 首页卡片不再显示星形图标和公开评分。
- SSR 首页商业合作卡片同步移除“广告”标记及“公开分”文案和评分值，避免首屏 HTML 与 React 接管后的页面不一致。
- 顶部“广告展位”和“独立于机场评分”说明保留，用于继续明确整个区域的商业合作属性和评分独立性。
- 官网链接继续保留 `rel="nofollow sponsored noopener noreferrer"`，营销曝光及点击追踪逻辑不变。
- 不修改优惠活动页、排行榜、机场报告、评分算法、广告计费、首页广告位排序或公共数据接口。
- 不修改 `gaterank-3.0/` 旧原型；当前生产实现以 `src/pages/home/HomePageV3.tsx` 和 `backend/src/services/publicPageRenderer.ts` 为准。

## 实现方案

采用直接删除对应展示节点的方式：

- 在 `SponsoredDealCard` 中删除右上角 `AD 广告` 标签。
- 在价格行中删除评分徽章，将价格信息保留在左侧，不新增替代内容。
- 在 `renderHomeV3SponsoredDeals` 中删除卡片顶部的“广告”元素。
- SSR 价格区只输出“月付起”和月付价格，不再拼接公开评分。

评分字段继续保留在首页数据契约中，供其它页面和既有业务使用。本次只改变商业合作卡片的展示，不缩减接口或数据库字段。

## 布局与兼容

- 删除右上角标签后，机场名称区域继续使用现有弹性布局和截断规则，不改变卡片尺寸。
- 删除评分徽章后，起步月付仍位于价格区左侧；按钮区位置和两列宽度保持不变。
- 空广告位卡片不受影响。
- 桌面端与移动端使用同一 React 卡片实现，因此同步生效。
- SSR 与 React 都不再向用户或辅助技术暴露卡片级广告标记和评分文本。

## 验证

- 更新首页源代码契约测试，确认商业合作卡片中不存在 `AD 广告`、评分徽章和 `scoreLabel(deal.score, deal.score_hidden)` 调用。
- 更新 SSR 路由测试，确认首页商业合作卡片不输出卡片级“广告”、`公开分`或对应评分值，同时保留顶部区域说明和 `rel="nofollow sponsored noopener noreferrer"`。
- 运行聚焦首页测试、前后端类型检查和生产构建。
- 重新生成并检查仓库跟踪的 `dist`，确保构建产物与源代码一致。
- 在桌面和移动视口检查卡片标题、价格、按钮对齐，确认删除后没有异常空白或横向溢出。
- 最后执行 `git diff --check`。
