# News Mermaid 流程图查看设计

## 背景与目标

GateRank 新闻正文目前使用 `NewsContentService` 把 Markdown fenced code 统一渲染为普通代码块。文章 `clash-verge-rev-subscription-routing-guide` 已正确保存 `mermaid` 语言标记，但公开新闻页没有 Mermaid 渲染能力，因此用户只能看到黑色源码框。

本次目标是让新闻正文中的 Mermaid 代码块自动显示为流程图，并支持点击放大查看。正式新闻页和后台预览页保持一致；普通代码块及没有 Mermaid 的新闻页不受影响。

## 方案选择

采用自托管 Mermaid 和独立前端入口：构建时把 Mermaid 与增强脚本产出为站内静态资源，新闻页仅在正文包含 Mermaid 代码块时加载。相比 CDN 方案，它不依赖第三方网络和远端版本；相比后端预生成 SVG，它不引入浏览器模拟、SVG 持久化和保存链路复杂度。

## 架构与数据流

1. `NewsContentService` 继续把 fenced code 输出为经过 HTML 转义的 `<pre><code>`，并保留 `data-language="mermaid"`。这保证未启用 JavaScript 或渲染失败时仍能读取源文本。
2. `renderNewsArticlePage` 检测文章 HTML 是否包含 Mermaid 语言代码块；只有命中时才输出独立 Mermaid 模块脚本。
3. Mermaid 增强脚本扫描新闻正文中的目标代码块，读取 `textContent`，使用 `securityLevel: strict` 渲染 SVG，再将成功结果装入流程图画布。
4. 放大按钮打开页面级对话框，复用已经渲染的 SVG。关闭时恢复背景滚动，并把焦点交还给触发按钮。
5. 语法错误或模块异常时保留原代码块并附加简短提示，单个失败图表不影响其他图表和正文。

## 视觉与交互

视觉主张是把黑色源码框替换为与新闻正文一致的白色图解画布：浅色一像素边框、24px 圆角和克制阴影。图表是主体，右上角只保留一个近黑色“放大查看”操作。

- 桌面端：图表适配正文宽度，过宽内容允许画布水平滚动。
- 移动端：保留可读的节点字号，不强制把整张长图压缩到窄屏；按钮满足至少 40px 触控尺寸。
- 放大层：覆盖视口，包含明确标题与关闭按钮；支持按钮关闭、遮罩关闭和 `Escape` 关闭。
- 可访问性：放大按钮具备可读名称和可见焦点；对话框声明语义；原始 Mermaid 文本作为无脚本和失败回退。

## 安全、性能与兼容性

- 只处理精确的 `data-language="mermaid"`，不执行文章内 HTML 或脚本。
- Mermaid 使用严格安全模式；渲染输入来自已清洗页面中代码节点的纯文本。
- 模块脚本只在包含 Mermaid 的新闻文章页输出，新闻列表页、普通文章页和站点其他页面不承担额外下载。
- 原有 SSR 标题、目录、结构化数据、正文文本和机器可读 Markdown 保持不变。
- 后台预览沿用同一个页面渲染器，自动获得相同能力。

## 验证标准

- `mermaid` fenced code 保留可识别语言标记，普通 fenced code 仍是普通代码块。
- 含 Mermaid 的文章页输出按需脚本；不含 Mermaid 的文章页不输出该脚本。
- 示例流程图成功渲染为 SVG，不再以黑色源码框作为正常态。
- 点击“放大查看”能打开全屏视图，背景点击、关闭按钮和 `Escape` 均可关闭，焦点正确返回。
- Mermaid 语法错误时仍显示原始源码和错误提示，正文其他区域可正常使用。
- 桌面与移动端真实浏览器验收通过。
- 聚焦测试、前后端 TypeScript 检查和生产构建通过；若仓库存在无关既有失败，将单独记录。

## 非目标

- 不为月度报告或其他 Markdown 表面扩展 Mermaid。
- 不增加图表编辑、缩放拖拽、PNG/SVG 下载或主题选择。
- 不修改现有文章内容，也不要求重新保存或发布文章。
