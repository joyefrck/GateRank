# 首页标签恢复原系统色系设计

## 背景

新版首页 `src/pages/home/HomePageV3.tsx` 使用局部 `FeatureTag` 组件渲染广告卡和排行榜标签。该组件维护了一套简化的关键词判断，未命中的标签统一显示为灰色，因此“风险观察”等标签与系统既有 `TagBadge` 语义色系不一致。

## 目标

- 首页标签继续保留新版首页当前的紧凑尺寸、间距和小圆角造型。
- 标签颜色改为复用 `src/components/TagBadge.tsx` 的既有语义映射。
- 首页广告卡、桌面排行榜和移动排行榜使用同一套颜色来源。
- 不改变首页以外页面的标签外观，也不改变标签文字、排序或数量。

## 方案

保留首页局部 `FeatureTag` 作为紧凑展示层，让它通过共享的 `getTagBadgeTone(tag)` 获取既有系统颜色类。首页只负责尺寸、圆角和排版，标签语义到颜色的对应关系继续由 `TagBadge` 集中维护。

不在首页复制“风险观察”“性价比高”等标签的颜色常量，也不直接替换为完整 `TagBadge` 组件，避免旧组件的胶囊尺寸和间距撑高新版首页卡片及表格。

## 影响范围

- `src/pages/home/HomePageV3.tsx`：接入共享标签色系，保留紧凑展示结构。
- 首页相关聚焦测试：验证代表性标签命中原系统颜色，并验证首页不再维护独立的灰色兜底色系。

## 验收标准

1. “风险观察”在首页呈现原系统的橙色语义色。
2. “性价比高”在首页呈现原系统的黄色语义色。
3. 其他已知标签和未知标签沿用 `getTagBadgeTone` 的确定性映射。
4. 首页标签仍保持当前紧凑尺寸和小圆角，不变成完整胶囊标签。
5. 广告卡、桌面排行榜和移动排行榜均通过同一 `FeatureTag` 生效。
6. 聚焦测试及前端构建通过。

## 非目标

- 不调整标签文案、标签来源或后台配置。
- 不重做首页布局、卡片间距或排行表格。
- 不修改其他页面的 `TagBadge` 样式。
