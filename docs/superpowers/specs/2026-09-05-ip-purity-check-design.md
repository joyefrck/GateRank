# IP 纯净度检测设计

用户已确认采用其他真实数据源，功能接近 ping0，不要求评分一致。

- 新增 `/tools/ip-purity-check`，工具目录和导航均可到达。自动查询当前出口，支持手动公网 IPv4 / IPv6、复制 IP、重新检测；复用 GateRank 公共布局。
- ipwho.is 提供现有归属地数据；proxycheck.io v3 只补充风险分数、代理/VPN/Tor/机房信号。风险越高越应关注，展示来源、查询时间和缓存标记，不宣称等于 ping0 或平台封禁概率。不转发供应商完整数据。
- 用户追加要求接入原生 IP：采用 IPOK 直接标签，加 RIPE NCC 注册国家与定位国家的一致性参考；明确标注直接判定、倾向、分歧、证据不足。共享人数暂不支持检测。网络类型仅展示有依据的机房识别；不能把“未检测到机房”推断成家庭宽带。
- 供应商请求仅由后端发送，支持可选环境变量 API Key；单次请求超时 5 秒，有界 1 小时缓存、并发合并、每日上游预算和客户端限流。上游配额耗尽/异常时允许基础数据继续展示，风险显示不可用。
- 后台 `/admin/ip-purity` 配置 Title、Description、Keywords、OG 图片及替代文本；保存到现有 admin_system_settings，不新增数据库表。空值恢复默认，拒绝非法图片 URL，沿用管理员鉴权及审计。
- SEO 配置由 API、SSR 和 React 共享，SSR 注入配置而不注入个人检测结果；包含 FAQ、WebApplication、面包屑、canonical、sitemap。配置保存后新请求立即获取新值。
- 聚焦测试覆盖真实字段归一化、未知值、缓存/超时/配额、非法目标、SEO 保存及 HTML 转义。运行完整测试、类型检查、构建，并在 Chrome 验证桌面、移动端和真实查询。
- 仅本地开发验证，不提交、推送或部署。

参考： https://proxycheck.io/api/ 、https://proxycheck.io/terms/ （2026-09-05 核实）。匿名额度为每日 100 次；可配置自有 Key 和相应预算扩容。
