# 机场优惠详情页 Sitemap 完整收录设计

## 目标

确保每个具有历史或当前优惠活动、且仍可公开展示的机场详情页 `/deals/:slug` 都进入动态 `/sitemap.xml`，不再依赖机场是否出现在排行榜前 100 条。

## 数据来源与合并规则

- 保留测评 sitemap 条目作为来源，使已有公开测评的机场继续获得优惠详情页地址。
- 合并 `AirportAdCampaignRepository.listDealSitemapUpdates()` 返回的活动机场 slug。该查询已限制为 `is_listed = 1`、非跑路、slug 非空的机场。
- 使用 slug 作为唯一键，同一机场只输出一个 `/deals/:slug`。
- 同时存在测评更新时间和活动更新时间时，`lastmod` 取字符串时间中较新的值；仅有活动记录时直接使用活动更新时间。
- 活动仓库读取失败时保留原有降级行为：记录错误并继续输出测评来源的优惠详情页，不让整个 sitemap 请求失败。

## 边界

- 不通过调大排行榜分页解决，因为任何固定上限都会再次漏收录。
- 不加入从未有优惠活动且没有公开测评的机场，避免制造无搜索意图的空页面。
- 不改变优惠详情页路由、过期页面保留策略、SEO 文案或 sitemap 缓存策略。

## 验收

- 测试覆盖“仅存在活动记录、没有排行榜测评条目”的机场仍进入 sitemap。
- 测试覆盖同一 slug 去重并使用较新的活动 `lastmod`。
- 本地 `/sitemap.xml` 中原有详情地址仍存在，新增测试输出数量准确。
- 相关测试、类型检查和生产构建通过。
