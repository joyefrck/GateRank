# 首页分类推荐达标轮换

用户已确认执行：性价比、长期稳定两个栏目按门槛准入，各自公平轮换。

- 全部已上架、正常且公开评分可见的机场参与筛选，不截取旧分类榜或首页优秀机场候选。当前日期的指标与评分必须齐全，匹配当前评分版本。
- 稳定性分至少 80、连续稳定至少 14 天、风险安全分至少 75，排除风险标签及现有风险判定命中的机场。性价比另需价格分至少 75、性能分至少 65。稳定性分和价格分采用现有标签规则的明细口径，缺失时使用评分分项。
- 两栏目复用轮换纯函数，在现有状态表中分别保存 id=2、id=3 的队列；id=1 的优秀机场不变。事务锁确保请求及实例共享顺序。轮换间隔沿用营销配置，显示数量沿用各栏配置。
- 完整候选先排队再截取；每轮各机场首位一次，候选失效立即退出，无人达标保持空态。评分波动只影响准入，不影响队列中的优先级。
- API 各栏目附带轮换时间；React 按三个队列中最早到期时间刷新。SSR 和 React 使用相同的性价比推荐标题与达标轮换说明，序号为展示顺序。
- 保留真实评分、正式榜单和计费规则。仅本地实施，不推送或部署，不改现有构建产物和上传文件。

验证：门槛边界、缺失/风险数据、完整候选、队列公平、退出恢复、并发与重启持久化、接口顺序/评分、SSR 文案、前端刷新、桌面/手机视图、类型检查和构建。
