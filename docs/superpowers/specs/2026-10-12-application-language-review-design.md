# 入驻申请语言攻击审核

用户已确认使用 DeepSeek，并采用不包含业务名称、行业背景的固定中性提示词。保留现有 Cloudflare Turnstile 后端验证；审核仅识别辱骂、人身攻击、威胁、群体仇恨和针对对象的攻击性脏话，不增加政治或行业判断。

- `system` 只包含固定规则；`user` 为服务端序列化的 `{ fields: { text_1, text_2 } }`。两个字段分别映射名称与简介，不透传原始请求体。
- 密码、测试账号、邮箱、Telegram、订阅地址和 token 不发送到模型。名称最多 128 字符、简介最多 4000 字符，前后端保持一致，不截断文本后放行。
- 同一后端服务保护公开提交、未支付资料编辑和运营资料编辑。审核必须位于申请、账号、钱包、邮件、通知、验证码消费及正式资料同步之前。
- 只允许 `allow` 且无 issues 的有效结果继续业务。`reject` 与 `review` 均阻止业务写入；超时、空响应、截断、无效结构和未知枚举返回 503。模型理由不直接展示或记录，前端只接收本地固定文案。
- 保留 IP+邮箱限流，增加独立 IP 总量限制；模型调用设置超时和进程内并发上限，不做自动重试。
- 服务端环境变量保存 API Key；生产默认要求审核配置，开发仅在显式启用或提供 Key 时开启。用户随后明确授权直接发布生产并配置 API，按检查、推送、同 SHA 镜像构建、备份、成对部署和验收执行。
- 页面保留原有结构，只调整等待文案、名称和简介长度限制、错误区域可访问性。失败保留表单；公开提交沿用现有 Turnstile reset。
- 使用 mock 测试确认安全边界和无副作用，使用合成文本进行真实 API 验证，不提交线上申请或使用已有生产资料。
