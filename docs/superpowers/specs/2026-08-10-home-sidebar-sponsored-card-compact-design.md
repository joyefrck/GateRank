# GateRank 首页侧栏广告卡片压缩设计

## 背景与目标

首页广告位已经移动到“探索更多优质机场”下方并按单列展示。实际页面中，占用广告卡仍因价格区、分隔区和原有最小高度显得偏高。此次调整隐藏首页广告卡中的价格展示，并把占用卡片压缩到约 168px、空广告位压缩到约 124px。

本设计是 `2026-08-10-home-sidebar-sponsored-layout-design.md` 的增量覆盖：上一份设计中关于“显示起步月付”和“占用卡片最小高度 196px”的要求由本文替代，其余位置、顺序、字段来源、链接、统计、响应式和 SSR 一致性要求继续有效。

## 视觉主张与内容层级

广告卡片应成为紧凑的侧栏推荐条目，而不是缩小版详情卡。浏览顺序保持为：

1. 机场标识、机场名称和观察天数。
2. 活动标题。
3. 最多两个标签。
4. 查看报告与官网入口。

价格不再参与首页卡片的信息层级。移除价格后，通过收紧间距和卡片内边距实现高度压缩，不缩小关键文字，不降低按钮触控高度，也不删除活动标题、标签或操作入口。

## 方案选择

### 采用：隐藏价格并压缩结构

删除价格区，卡片最小高度改为 168px，内边距约 14px，内容间距控制在 6–8px。标签下方保留轻量分隔线，两个操作按钮继续并排并保持至少 40px 高度。

该方案能比当前实际约 240px 的占用卡片减少约三成高度，同时保持完整的推荐信息和可操作性。

### 不采用：只隐藏价格

如果保留 196px 最小高度和原有间距，删除价格后会留下多余空白，视觉压缩不明显。

### 不采用：压缩到约 152px

继续缩小字体、标签或按钮可以进一步降低高度，但会损害扫描效率和移动端触控体验，不符合 GateRank 至少 40px 触控目标。

## React 卡片调整

目标文件为 `src/pages/home/HomePageV3.tsx`。

`SponsoredDealCard` 调整如下：

- 移除“起步月付”、价格值和“/起”的整块 JSX。
- 保留 `SponsoredDeal.plan_price_month` 类型和首页 API 数据，不修改后台、详情页或其他页面的价格展示。
- 最小高度从 196px 改为 168px。
- 圆角继续为 18px。
- 内边距从 16px 调整为约 14px。
- 顶部内容组间距压缩到 6–8px。
- 机场标识继续为 36 × 36px。
- 机场名称、观察天数、两行活动标题和最多两个标签全部保留。
- 标签内容之后保留浅灰分隔线，再进入操作区。
- 操作区继续为两列等宽、8px 间距。
- 两个按钮继续保持至少 40px 高度、主次色层级和可见焦点状态。
- 现有 2px 悬停上移保持不变。

`SponsoredEmptySlot` 最小高度从 140px 调整为约 124px。空位标题、位置编号、申请链接和 40px 操作区域全部保留。

## SSR 卡片调整

目标文件为 `backend/src/services/publicPageRenderer.ts`。

- 从 `renderHomeV3SponsoredDeals` 的有效广告卡中移除 `.home-v3-deal-bottom` 价格结构。
- 不改变 `deal.plan_price_month` 的服务端数据模型或其他渲染器用法。
- `.home-v3-deal` 最小高度改为 168px，内边距改为 14px。
- 删除只服务于价格区的 `.home-v3-deal-bottom`、其 `small` 和 `strong` 样式。
- 操作区继续使用两列和 40px 最小高度。
- 空广告位使用独立紧凑高度，目标约 124px；不伪造价格或其他有效广告字段。

SSR 与 React 都不应出现“起步月付”“月付起”、价格值或“/起”。

## 数据与行为边界

以下内容不得改变：

- 首页 API 仍返回 `plan_price_month`，后台和其他页面仍可使用该字段。
- 五个固定广告位置、位置顺序和空位语义不变。
- 机场名、观察天数、`discount_title`、标签、报告链接和官网链接不变。
- React 曝光继续使用 `placement: 'deal_card'` 和原有去重键。
- 官网点击继续使用现有营销事件处理器。
- 官网链接继续保留 `target="_blank"` 和 `rel="nofollow sponsored noopener noreferrer"`。
- 查看报告仍为可抓取的真实站内链接。

## 响应式与可访问性

- 桌面、平板和手机都继续每行一张广告卡。
- 卡片以 168px 为最小高度；标题或标签内容需要更多空间时允许自然增高，不裁切字段。
- 两个操作按钮在 390px 手机视口仍保持并排；每个按钮至少 40px 高。
- 不增加横向滚动。
- 键盘焦点、悬停反馈和 `prefers-reduced-motion` 行为不变。

## 测试与验收

### 自动化回归

- React 源码测试断言 `SponsoredDealCard` 不再读取或显示 `deal.plan_price_month`。
- React 源码测试断言卡片使用 168px 最小高度、约 14px 内边距和两列 40px 操作按钮。
- React 源码测试断言空位使用约 124px 最小高度。
- SSR 路由测试断言广告卡 HTML 不包含“月付起”和价格区结构。
- SSR 路由测试断言 `.home-v3-deal` 使用 168px 最小高度和 14px 内边距。
- 保留广告字段、链接属性、五个槽位和统计逻辑的现有断言。
- 运行聚焦测试、前后端 TypeScript 检查、全量后端测试和 Vite 生产构建。

### 浏览器验收

- 桌面占用广告卡实际高度接近 168px；内容增长时允许略高，但不应保留价格区空白。
- 390px 手机下按钮仍为 40px 高且不换行。
- 空广告位实际高度接近 124px。
- 桌面、平板、手机均无横向溢出。
- SSR 首屏和 React 接管后的卡片都不显示价格，位置和高度不发生明显跳变。

## 非目标

- 不从 API、数据库或后台表单删除价格字段。
- 不修改优惠活动页、详情页或其他价格展示。
- 不修改广告购买、续费、计费或钱包逻辑。
- 不修改广告位数量、顺序或侧栏位置。
- 不推送或部署生产环境。
