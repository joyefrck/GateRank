# 首页指定轮换名单

用户已确认：营销模块的首页展示增加可搜索机场多选，支持保存、回显和移除。名单中的机场跳过付费入驻、充值记录、余额及节点数量门槛，仍须上架且状态为 normal/risk。名单与普通候选去重后共同公平轮换，沿用间隔、展示数量及每轮首位机制。评分、扣费和其他榜单不变。

配置使用 marketing_billing.home_rotation_airport_ids，默认空数组；旧配置兼容，省略字段保留原名单，空数组清空。后端验证正整数及机场存在性。首页服务传递名单至候选服务，复用持久化轮换队列，SSR 和 React 共用首页结果。公开规则说明同步更新。

大象网络由启动初始化迁移按唯一同名真实记录解析 ID；仅当配置尚无该字段时初始化。找不到记录或同名记录不唯一时跳过，不伪造机场。已保存的名单（包括空数组）优先，重启不撤销管理员移除操作。轮换业务代码不写死名称或 ID。本次在当前分支实施及本地验证，不包含生产发布。

验收：配置保存及刷新回显；无钱包、未付款、未充值、余额不足、无节点的指定机场可入队；下架、删除或停运机场不入队；重复项去重；移除恢复普通资格判断；轮换顺序、计费和其他榜单不变；桌面及手机界面可操作。


## 验证结果

- 前后端类型检查通过，生产构建通过（输出到临时目录，保留已有 dist）。
- 全量后端测试 1094 项：1089 通过、5 项环境相关跳过、0 失败；单独连接本地 MySQL 的轮换/初始化集成测试通过。
- 1280px 桌面和 390px 手机均验证无横向溢出。真实管理页面完成搜索、勾选、保存、刷新回显及移除。
- 本地测试机场保存后出现在首页 API 与浏览器表格中，移除后候选恢复为空；测试配置已还原。
- 本地数据库没有大象网络真实记录；加入真实大象网络将在部署初始化时生效，本次未推送或部署生产。
