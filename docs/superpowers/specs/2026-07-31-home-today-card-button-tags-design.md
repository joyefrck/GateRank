# 首页今日推荐卡片按钮与标签微调设计

## 目标

仅调整首页“今日推荐机场”卡片，使“访问官网”恢复为旧版黑色主按钮，并让标签更紧凑、最多可展示三个且不显示标签内圆点。其它页面、数据契约、跳转、曝光和点击计费行为保持不变。

## 范围

- React 首页 `HomeTodayPickCard`。
- 服务端首页公开页渲染器中的今日推荐卡片。
- 公共 `TagBadge` 组件只扩展可选能力，默认外观保持不变。
- 不调整排行榜、详情页、风险监测、优惠页等其它标签。

## 视觉设计

### 访问官网按钮

- 背景恢复为旧版深黑 `slate-950`。
- 悬停态使用 `slate-800`。
- 保留白色文字、外链图标、现有尺寸、圆角、键盘焦点和点击追踪。
- SSR 使用对应的深黑背景与白色文字。

### 首页标签

- 首页最多仍使用接口返回标签的前三个。
- 新增 `xs` 紧凑尺寸，字体约 10px，缩小水平和垂直内边距以及标签间距。
- 新增 `showDot` 可选参数；默认值为 `true`，首页传入 `false`。
- 标签文本保留现有色彩语义和圆角边框。
- 三个标签优先在同一行展示；超长标签允许截断，但不隐藏整个标签。
- SSR 输出三个独立的小标签元素，不使用圆点或中点文本分隔。

## 组件设计

`TagBadge` 增加：

```ts
size?: 'xs' | 'sm' | 'md';
showDot?: boolean;
```

默认值继续是 `size="md"` 和 `showDot={true}`，因此现有调用点不需要修改，也不会发生全站视觉回归。

首页调用：

```tsx
<TagBadge tag={tag} size="xs" showDot={false} />
```

## 行为与兼容性

- 官网链接继续使用 `/api/v1/outbound/airports/:id`。
- `createTrackedOutboundClickHandler`、曝光统计和计费逻辑不变。
- 测评按钮、图表、价格、评分、排名和移动端横向吸附不变。
- SSR 与 React 保持相同按钮颜色、标签数量和无圆点表现。

## 验证

- 运行 `npm run lint` 和 `npm run build`。
- 运行首页 SSR 与后端相关测试。
- 在 1440px 和 390px 检查：
  - 官网按钮为黑色，悬停与焦点清晰。
  - 首页标签内没有圆点。
  - 三个短标签可同时显示。
  - 长标签不会撑破卡片或造成页面横向溢出。
  - 其它页面标签仍保留圆点。
- 更新根目录 `design-qa.md`，最终结果必须保持 `passed`。
