# 首页广告卡整卡官网入口设计

## 背景

首页右栏广告卡已隐藏价格和标签，并移除卡片底部“查看报告”和“官网”按钮，把整个占用广告卡改为官网入口并压缩到 `88px`。在操作区已经移除后，机场名称左侧恢复一个紧凑首字图标，以补足品牌识别，同时继续控制右栏视觉重量。

## 视觉主张

广告卡成为安静、轻量的品牌入口：只保留紧凑首字图标、机场名称、观察天数和活动标题，通过整卡悬浮与焦点反馈表达可点击性，不增加按钮、箭头或提示文案，让左侧 GateRank 排行榜继续承担页面视觉重心。

## 占用广告卡

### 内容

从上到下只显示：

1. 名称左侧显示 `30px × 30px` 紧凑首字图标。
2. 图标右侧显示单行机场名称和观察天数。
3. 下方显示单行活动标题。

以下内容不在首页广告卡中展示，但不删除数据字段：

- 查看报告入口。
- 独立官网按钮。
- 月付价格。
- 机场标签。
- 优惠码标签。

### 尺寸与布局

- 目标高度为 `88px`，相较当前 `136px` 减少 `48px`。
- 使用 `18px` 圆角、现有浅边框、白色至浅灰背景和克制阴影。
- 内边距约为 `10px 12px`。
- 首字图标复用现有 `AirportMark` 的颜色算法、渐变、圆角和阴影，使用 `compact` 尺寸，不引入新的品牌字段或图片资源。
- 图标与名称信息间距为 `8px`；图标标记为装饰性内容，不重复朗读机场名称。
- 名称和活动标题均限制为单行省略，不能把卡片撑高。
- 不增加分隔线、底部操作区或装饰图形。

### 链接与交互

- 整张卡片是唯一可交互元素，点击任意位置打开机场官网。
- 官网固定在新标签页打开。
- 链接保留 `nofollow sponsored noopener noreferrer`。
- 链接提供包含机场名称和“新标签页”语义的可访问名称。
- hover 时卡片轻微上移、边框转为淡靛蓝并适度加强阴影。
- active 时轻微压缩，`prefers-reduced-motion` 下取消位移动画。
- focus-visible 时显示清晰焦点环。

## 广告追踪

- 整卡点击继续调用现有 `createTrackedOutboundClickHandler`。
- `airportId`、`campaignId`、`pageKind: 'home'`、`placement: 'deal_card'`、`targetKind: 'website'` 和目标 URL 保持不变。
- 曝光追踪继续使用现有 `useMarketingImpression` 和相同去重键。
- 不增加重复链接或重复点击事件，单次点击只产生一次官网外跳追踪。

## 空广告位

- 空广告位同步压缩到约 `88px`，保持同列节奏。
- 整张空位卡继续链接到 `/apply`。
- 移除内部按钮外观，使用普通文字显示“首页 N 号广告位招募中”和“申请入驻”。
- 不增加嵌套链接或按钮。
- 保留虚线边框、轻微 hover 和 focus-visible 反馈。

## React 与 SSR 一致性

- React 使用整卡外链元素承载官网跳转、曝光 ref 和点击追踪。
- SSR 直接输出整卡官网链接，确保未执行 JavaScript 时仍可点击和抓取。
- React 与 SSR 均显示相同的紧凑首字图标、名称、观察天数和活动标题。
- 两侧均不渲染底部操作区、报告链接、独立官网按钮、标签和价格。
- 两侧占用卡目标高度均为 `88px`，空位卡视觉高度保持一致。

## 验收标准

- 桌面和 390px 移动端中，占用广告卡实测高度约为 `88px`。
- 空广告位高度约为 `88px`，无内部按钮外观。
- 整张占用卡仅包含一个官网链接，点击后在新标签页打开。
- 卡片内不存在报告链接、独立官网按钮或嵌套交互元素。
- 卡片内不存在价格、标签和优惠码；名称左侧存在一个装饰性 `30px` 首字图标。
- 名称与活动标题过长时单行省略，页面和卡片均无横向溢出。
- 官网链接属性、点击追踪和曝光追踪全部保留。
- React 与 SSR 的字段可见性、整卡链接语义和尺寸一致。
- React 与 SSR 控制台无新增警告或错误。
- 相关静态契约测试、公共路由测试、TypeScript 检查、全量后端测试和生产构建通过。

## 非目标

- 不修改广告数据模型、接口、后台配置或投放规则。
- 不删除 `report_url`、`plan_price_month`、`tags` 或 `coupon_code` 字段。
- 不修改机场详情页、优惠详情页或其他页面的报告、官网、标签和价格展示。
- 不修改左侧 GateRank 排行榜及其操作按钮。
- 不改变广告位数量、排序或商业合作专区标题。
