# 热门工具发布日期响应式布局设计

## 目标

修复公开工具下载页中热门徽标压缩版本与发布日期空间的问题：

- 大屏幕保持“版本 · 发布日期”单行展示。
- 小屏幕空间不足时允许换成两行。
- 不使用省略号隐藏发布日期。
- 保持热门徽标在卡片右上角的现有视觉位置。

## 根因

服务端渲染会为整个热门卡片头部预留徽标空间；React 接管页面后也会缩窄整个头部，并给版本与日期行应用 `truncate`。窄卡片中，热门徽标减少了元信息的可用宽度，React 最终以省略号截断发布日期。

## 设计

### 徽标避让范围

热门徽标继续绝对定位在卡片右上角，但只由软件名称标题行预留右侧空间。版本与发布日期行不再继承这段右侧留白，因为它位于徽标下方，可以使用图标右侧的完整内容宽度。

### 响应式元信息

- React 卡片移除版本与日期行的 `truncate`。
- 小屏幕使用正常换行和稳定行高，必要时显示两行。
- `sm` 及以上断点使用 `white-space: nowrap`，保持单行。
- 服务端 HTML 使用等价类名和媒体查询，确保首次渲染与 React 接管后的布局一致。

## 边界

- 软件名称仍允许单行截断，避免与热门徽标重叠。
- 不修改版本、发布日期的数据来源和文案。
- 不改变卡片描述、支持版本、文件大小、下载按钮或官方链接布局。
- 非热门卡片沿用同一元信息换行规则，不产生额外视觉分支。
