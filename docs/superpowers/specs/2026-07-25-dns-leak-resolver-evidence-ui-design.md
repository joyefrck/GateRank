# DNS Leak Test 解析器证据 UI 设计

## 背景

当前 DNS Leak Test 已能列出权威探针实际观察到的递归解析器 IP、国家、运营商、ASN、观察次数和查询类型。但现有列表使用无表头的自由网格，普通用户难以理解以下信息：

- 每一行为什么会出现，以及同一家运营商为什么可能出现多行。
- 解析器 IP 当前按什么顺序排列。
- `AS15169` 等 ASN 数据表示什么。
- `1 次观察 · A`、`3 次观察 · A, AAAA, HTTPS` 的统计口径和技术含义。
- 英文国家名对应哪里。

本次改动只优化解析器证据区的信息表达、排序、中文解释和响应式布局，不改变 DNS 探针、会话、安全规则、风险判定或公开 API 字段。

## 目标

1. 普通用户无需了解 DNS 协议即可理解每一行的含义。
2. 技术用户仍能看到原始 IP、组织、ASN 和查询类型证据。
3. 桌面端具有清楚、稳定的数据表结构。
4. 移动端无需横向滚动即可查看完整证据。
5. 排序规则明确，并优先展示本轮参与度更高的解析器。

## 非目标

- 不把 ASN、运营商不同或查询类型本身解释为泄漏。
- 不推断解析器的精确城市或机房。
- 不改变 `no_obvious_leak`、`possible_leak`、`inconclusive` 的判定规则。
- 不新增数据库字段、迁移或公开 API 字段。
- 不尝试通过查询类型判断用户是否使用 DoH 或 DoT。

## 术语与统计口径

### 每一行代表什么

每一行代表 GateRank 独立权威 DNS 探针实际观察到的一个递归解析器来源 IP。同一家公共 DNS 服务可能通过负载均衡、Anycast 或分布式递归集群使用多个来源 IP，因此相同运营商出现多行不等于重复或异常。

### 命中测试域名

现有 `observation_count` 是该解析器关联到的唯一 `probe_index` 数量。一个解析器对同一测试序号产生多条 DNS 查询时，只计算一次。

界面不再显示“3 次观察”，改为：

> 命中 3/10 个测试域名

该文案明确表达统计对象是本轮 10 个专属测试域名，而不是网络请求次数、测速次数或异常次数。

### ASN

ASN 是 Autonomous System Number，即自治系统编号。自治系统是一组由同一机构管理并采用统一路由策略的互联网网络。

界面显示：

> 自治系统编号 AS15169

ASN 仅用于说明 IP 的网络归属，不是地理位置、服务器编号或风险等级。

### 查询类型

查询类型以固定顺序显示，并提供中文解释：

| 原始类型 | 中文界面文案 | 含义 |
| --- | --- | --- |
| `A` | `A · IPv4 地址查询` | 查询域名对应的 IPv4 地址 |
| `AAAA` | `AAAA · IPv6 地址查询` | 查询域名对应的 IPv6 地址 |
| `HTTPS` | `HTTPS · HTTPS 服务参数查询` | 查询 HTTPS 服务连接参数和能力信息 |
| 其他类型 | `<TYPE> · 其他 DNS 查询` | 保留原始类型，避免隐藏技术证据 |

查询类型表示递归解析器为浏览器或系统处理了哪些 DNS 问题，不能单独证明使用了 DoH、DoT 或发生 DNS 泄漏。

## 排序与聚合

### 聚合

服务端继续按标准化后的解析器 IP 分组：

1. 同一解析器 IP 的观察记录合并为一行。
2. `observation_count` 按唯一 `probe_index` 去重。
3. `query_types` 去重后按固定语义顺序排列。
4. DNSSEC 信号继续根据该解析器是否出现 EDNS DO 标志计算。

### 排序

解析器列表采用稳定排序：

1. `observation_count` 从多到少。
2. 数量相同时按 IP 升序。

界面在表格标题下常驻显示：

> 按本轮命中测试域名数量从多到少排列；数量相同时按 IP 排序。

“检测到 32 个解析器”表示观察到 32 个不同解析器来源 IP，不表示使用了 32 家 DNS 服务商。

## 中文地区显示

前端优先使用 `country_code` 通过标准区域名称能力转换为简体中文国家或地区名，例如：

- `CN` → `中国`
- `JP` → `日本`
- `SG` → `新加坡`
- `US` → `美国`

显示优先级：

1. 可识别的 `country_code` 对应中文名称。
2. 无法转换时使用 API 返回的 `country`。
3. 两者均缺失时显示“地区未知”。

位置列下方增加低对比度提示：

> IP 数据库估算的网络注册地区，不代表精确机房位置。

不根据 IP 或运营商名称猜测城市。

## 桌面端布局

桌面端使用语义化 `<table>`，包含四列：

| 列 | 主信息 | 辅助信息 |
| --- | --- | --- |
| 解析器 IP | 完整 IPv4 或 IPv6 地址 | 无 |
| 位置 | 中文国家或地区 | IP 地理估算提示 |
| 所属网络 | `organization`，缺失时回退 `isp` | `自治系统编号 <ASN>` |
| 查询证据 | `命中 X/10 个测试域名` | 查询类型中文标签 |

视觉规则：

- 表头使用浅灰背景和清晰列名。
- 行间只保留细分隔线，不为每行增加独立卡片或阴影。
- IP 使用等宽字体，允许长 IPv6 地址换行。
- 位置、所属网络左对齐。
- 查询证据列主数据右对齐，标签在桌面宽度不足时允许换行。
- 去除每行重复的服务器图标，降低视觉噪音。
- 红色和绿色只用于最终风险状态，不用于普通查询类型或 ASN。

## 移动端布局

移动端采用已确认的 B1“标签化纵向表”，不使用横向滚动。

每个解析器区块结构：

1. 首行左侧显示完整 IP，右侧显示“命中 X/10 个测试域名”。
2. 下方使用标签和值的两列布局：
   - 位置
   - 所属网络
   - 自治系统编号
   - 查询类型
3. 查询类型使用可换行的中性标签。
4. 区块之间只使用分隔线，不增加独立卡片背景。

桌面表格和移动列表共享格式化函数，确保排序、中文国家名、ASN 和查询类型文案一致。

## 常驻说明

解析器证据标题与表格之间增加低对比度说明区，不依赖悬浮提示：

> 每一行代表一个实际访问 GateRank 权威探针的递归 DNS 服务器 IP。同一家公共 DNS 可能使用多个服务器 IP，因此相同运营商的多行记录不一定是重复或异常。

说明区同时包含三个短定义：

- `AS 编号`：该 IP 所属互联网网络的自治系统编号，不是风险等级。
- `命中测试域名`：该解析器处理了本轮 10 个测试域名中的几个。
- `A / AAAA / HTTPS`：IPv4、IPv6 和 HTTPS 服务参数查询，不能据此判断 DoH 或 DoT。

## 复制结果

复制文本与页面使用相同排序和中文格式：

- 国家或地区使用中文名称。
- ASN 使用“自治系统编号”前缀。
- 观察次数改为“命中 X/10 个测试域名”。
- 查询类型附带中文解释。
- 保留 DoH、DoT 无法可靠判断的能力边界。

## 状态与错误处理

- 检测中：保留现有等待区，不渲染空表头数据。
- 部分结果：显示已观察到的解析器，并明确当前是部分证据。
- 无解析器：继续显示“本轮未发现解析器，结果无法判定”。
- 地区缺失：显示“地区未知”，风险判定保持 `inconclusive`。
- 组织或 ASN 缺失：分别显示“所属网络未知”“自治系统编号未知”。
- 未知查询类型：保留原始类型并标为“其他 DNS 查询”。

## 可访问性

- 桌面端使用 `<table>`、`<thead>`、`<tbody>` 和列标题。
- 移动端字段标签使用可被辅助技术读取的文本，不只依赖位置或颜色。
- 只渲染当前断点对应的可访问结构，避免屏幕阅读器重复朗读桌面和移动内容。
- 中性色查询标签保持足够对比度。
- 动画继续遵守 `prefers-reduced-motion`。

## 测试

### 单元测试

- 观察数量降序与相同数量 IP 升序。
- 同一解析器和测试序号的重复观察去重。
- 查询类型固定顺序与未知类型回退。
- 国家代码转换为中文名称及未知地区回退。
- ASN、命中数量和查询类型中文文案。
- 复制结果使用新排序与新文案。

### 页面与公共面测试

- 桌面表格包含四个列标题。
- 常驻说明包含多 IP、ASN 和查询类型边界。
- 移动端包含 B1 字段标签，且不存在强制横向滚动容器。
- 长 IPv6 地址可换行。
- 检测中、部分结果、空结果和地区缺失状态保持可读。
- SSR 和现有 SEO 元数据继续包含 DNS Leak Test 页面内容。

### 回归验证

- DNS Leak Test 聚焦测试。
- `npm run test:backend`。
- `npm run lint`。
- `npm run server:typecheck`，如仍存在仓库既有类型债务，单独列明且不得新增本次相关错误。
- `npm run build`。

## 发布边界

设计确认后的实现将修改共享格式化/排序逻辑、DNS Leak Test 页面和相应测试。生产发布、主机环境或 DNS 记录不属于本设计确认步骤；实现完成并通过验证后再单独执行发布。
