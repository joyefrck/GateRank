# 网络覆盖 N 历史时间衰减

用户已确认方案，并要求后续不再重复询问。

## 目标与规则

所有机场的网络覆盖 N 使用与 S/P/R 相同的指数时间权重：`exp(-0.1 * daysDiff)`；按有效日原始 N 求加权平均后参与现有 20% 总分权重，上涨、下跌对称处理。不添加固定每日涨跌上限。

- 使用截至评分日期的有效历史日分，不限制额外窗口；未来日期、无效日期、缺失、非有限或超出 0–100 的 N 不参与计算。真实 0 分参与。
- 同一天只保留一个有效观测；当天最新原始 N 替换旧值。重复重算不得增加样本数或将已衰减值再次输入历史。
- 无历史时使用当天有效原始 N。没有成功覆盖采集的日期继续沿用现有不发布日分、公开页面回退最近有效评分的行为，不制造 0 分。
- `airport_scores_daily.score_n` 和覆盖采集记录保持原始值；`details.automatic_score_n` 存放衰减结果。人工分项覆盖继续在自动计算之后应用，不污染历史。
- 批量重算、单机场重算、事务内评分保存和后台预览统一使用该规则；v1 不引入 N，冷启动计算不变。
