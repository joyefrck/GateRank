# GateRank 首页广告位右侧栏布局设计

## 背景与目标

首页当前把“商业合作专区”作为独立全宽区域放在 Hero 与排行榜之间，并将五个广告位横向排列。此次调整把整个广告区移动到首页右侧栏，位置固定在“探索更多优质机场”下方、“实用工具”上方。五个广告位在所有视口中都按位置顺序纵向排列，每行一张。

本次只改变首页展示位置、卡片编排和对应尺寸，不改变广告数据字段、广告位数量、排序、空位语义、计费、曝光、点击跟踪或跳转行为。

## 视觉主张与层级

广告区应表现为“经过明确标识的侧栏推荐流”：信息完整、广告属性清晰，但不与首页排行榜争夺第一视觉层级。

首页主体层级保持为：

1. 左侧排行榜是主要内容与视觉核心。
2. 右侧“探索更多优质机场”是侧栏首要引导。
3. 商业合作专区紧随探索入口，作为完整但克制的推荐流。
4. 实用工具和公告动态继续位于广告区之后。

广告容器继续使用首页现有的白色表面、浅灰边框、轻阴影和 24px 圆角。卡片继续使用深色主操作、白色描边次操作和靛蓝语义强调，不增加渐变、重阴影或新的强调色。

## 方案选择

### 采用：侧栏紧凑完整卡片

保留每张广告卡的机场标识、机场名、观察天数、优惠标题、标签、起步月付、查看报告和官网入口，通过横向排列两个操作按钮和收紧垂直间距，把单卡控制在约 196px 的最小高度。

该方案在约 390–405px 的桌面右侧栏中仍有清晰的信息层级，并能保留至少 40px 的按钮触控高度。

### 不采用：原卡片原尺寸直接搬移

当前卡片的操作按钮纵向堆叠，单卡最小高度约 215px。五张卡移入侧栏后会形成过长且重复的操作区，弱化工具与公告的可发现性。

### 不采用：极简横条

把单卡压缩到约 140px 虽能缩短侧栏，但标签、价格和两个操作入口会互相竞争，无法在不隐藏字段的前提下保持清晰层级。

## React 页面结构

`src/pages/home/HomePageV3.tsx` 的主体结构调整为一个十二列区域：

- 左侧八列继续渲染 `RankingPreview`。
- 右侧四列的 `HomeSidebar` 接收 `sponsored_deals.items`。
- 原本位于十二列区域上方的独立 `SponsoredDeals` 调用被移除。

`HomeSidebar` 内部顺序固定为：

1. 探索更多优质机场。
2. 商业合作专区。
3. 实用工具。
4. 公告与动态。

`SponsoredDeals` 继续负责五个固定槽位的映射与空位渲染，但其外层改为适配侧栏宽度的单列容器。`SponsoredDealCard` 和 `SponsoredEmptySlot` 继续复用既有数据与行为，不创建第二套广告组件或字段模型。

## 尺寸与响应式规格

### 广告区域

- 宽度：右侧栏 `100%`，桌面内容宽度约 390–405px。
- 外层圆角：24px。
- 外层边框：1px 浅灰。
- 外层内边距：20px。
- 标题：17px；较宽视口可保持现有 18px 上限。
- 标题区与列表间距：16px。
- 卡片垂直间距：12px。
- 广告属性标识、独立评分说明和申请入驻入口全部保留；窄宽度下允许标题区自然换行。

### 有效广告卡

- 宽度：100%。
- 最小高度：196px；内容增长时允许自动增高，不裁切字段。
- 圆角：18px。
- 内边距：16px。
- 边框：1px 浅灰。
- 机场标识：36 × 36px。
- 机场名称：15px，800–900 字重，单行省略。
- 观察天数：11px 等宽字体。
- 优惠标题：12.5px，最多两行。
- 标签：继续显示最多两个，沿用 `FeatureTag` 颜色体系。
- 价格：15px 等宽字体，沿用靛蓝强调。
- 操作区：两列等宽，列间距 8px；按钮高度至少 40px。
- “查看报告”：近黑填充主按钮。
- “官网”：白底浅灰描边次按钮，保留外链图标。

### 空广告位

空位继续显示对应位置的招募信息和申请入口，不改变槽位语义。空位宽度、18px 圆角、边框和卡片间距与有效广告卡一致；高度可按内容自适应，不用伪造有效广告字段来填满 196px。

### 交互反馈

- 卡片悬停最多上移 2px，并使用浅靛蓝边框与克制阴影。
- 主次按钮保留现有颜色层级，并提供清晰的 `focus-visible` 状态。
- 动效遵守 `prefers-reduced-motion`，不影响键盘和触控操作。

### 移动端与平板

- 小于 `lg` 时十二列主体退化为单列，排行榜在前，整个右侧栏在后。
- 右侧栏内部仍保持“探索 → 广告 → 工具 → 公告”的顺序。
- 五个广告位始终单列，每行一张，不改为双列，也不增加横向滚动。
- 广告卡高度改为内容自适应；按钮仍保持两列和至少 40px 高度。若最窄支持宽度下按钮文案无法稳定容纳，可仅在该断点退为上下两行，但字段和顺序不变。

## SSR 一致性

`backend/src/services/publicPageRenderer.ts` 必须与 React 输出相同的内容顺序和语义：

- 从 `.home-v3-main` 顶层移除独立的 `renderHomeV3SponsoredDeals(view)`。
- 在 `renderHomeV3Sidebar(view)` 的探索区域之后插入广告区域。
- SSR 补齐与 React 对应的“探索更多优质机场”侧栏区域，避免首屏 SSR 与 hydration 后出现结构跳变。
- `.home-v3-deal-grid` 在桌面、平板和移动端都使用单列。
- SSR 广告卡使用与 React 等价的紧凑尺寸、两列操作区和视觉层级。

SSR 标题 ID、广告卡数量、字段文本和链接属性继续满足现有爬虫与公共路由测试。

## 数据、跟踪与可访问性边界

以下行为不得改变：

- 按 `AIRPORT_HOME_AD_SLOTS` 渲染五个固定位置并保持位置顺序。
- 有效广告继续使用 `campaign_id`、`airport_id`、`home_slot`、`name`、`tracking_days`、`discount_title`、`tags`、`plan_price_month`、`report_url` 和 `website`。
- React 曝光继续使用 `placement: 'deal_card'` 和 `home|deal_card|${campaign_id}` 去重键。
- 官网点击继续走现有营销事件处理器。
- 官网链接继续保留 `target="_blank"` 与 `rel="nofollow sponsored noopener noreferrer"`。
- 查看报告继续使用可抓取的真实链接并保持站内导航行为。
- 区域继续由标题与 `aria-labelledby` 关联；右侧栏的 `aside` 语义不变。

## 错误与空状态

广告列表本身不增加新的网络请求或独立错误状态，继续随首页数据统一加载。没有有效广告时仍渲染五个空槽位，并保留屏幕阅读器可感知的“当前暂无有效广告”说明。

## 测试与验收

### 自动化回归

- 更新 React 源码结构测试，断言广告数据传入 `HomeSidebar`，并断言侧栏中探索、广告、工具、公告的相对顺序。
- 更新 SSR 公共页面测试，断言五张广告卡位于 `.home-v3-sidebar` 内且在探索区域之后。
- 断言桌面及移动端 `.home-v3-deal-grid` 都为单列。
- 保留五个广告位、字段内容、空位文案、链接属性和广告标识的现有断言。
- 运行相关后端公共页面与前端可抓取链接测试。
- 运行前端 TypeScript、后端 TypeScript、lint 和生产构建。

### 浏览器验收

- 桌面宽屏：排行榜保持主列，右侧广告区宽度与探索/工具容器一致，五张卡每行一张。
- 平板：主体切为单列后，探索、广告、工具、公告顺序正确。
- 手机：无横向溢出，字段不丢失，按钮触控高度至少 40px。
- 有效位与空位混合时，位置顺序稳定。
- hover、键盘 focus、报告跳转和官网外链样式清晰。
- SSR 首屏与 React 接管后不存在广告区位置跳变。

## 非目标

- 不修改广告位数量、后台配置、购买或续费流程。
- 不修改优惠活动字段或首页 API 响应。
- 不修改广告计费、曝光去重或点击统计口径。
- 不修改排行榜、工具和公告内容。
- 不部署生产环境。
