# 优惠卡片复制图标设计

## 目标

将优惠卡片底部的“复制优惠码”文字按钮移除，把复制操作放到优惠码值右侧，以紧凑的图标按钮呈现。列表页和单机场优惠详情页共用同一个 `DealCard`，因此两处同步生效。

## 界面行为

- 优惠码值保持现有蓝色标签样式。
- 标签右侧增加一个独立的 28×28 像素复制图标按钮，始终可见。
- 默认显示复制图标；复制成功后短暂显示勾选图标，再自动恢复。
- 图标按钮提供 `aria-label` 和 `title`：默认“复制优惠码”，成功时“优惠码已复制”。
- 移除卡片底部黑色“复制优惠码”按钮。
- 底部操作区保留“优惠详情”“查看测评”“访问官网”，并根据实际按钮数量自适应排列。

## 代码边界

- 只修改共享卡片 `src/pages/deals/DealCard.tsx` 及其相关回归测试。
- 不修改优惠数据接口、复制内容、统计埋点、SSR 内容或 SEO。
- 不新增组件依赖，继续使用现有 `lucide-react` 图标与 Clipboard API。

## 异常处理

- Clipboard API 成功时显示勾选反馈 1.8 秒。
- 复制失败时保持复制图标，不显示错误成功态，行为与当前实现一致。

## 验收标准

- 优惠码右侧存在可点击的仅图标复制按钮。
- 底部不再出现黑色“复制优惠码”按钮。
- 点击后复制的内容仍是当前卡片的 `coupon_code`。
- 列表页与详情页均生效。
- 前端类型检查、聚焦回归和生产构建通过。
