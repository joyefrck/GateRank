# 网络覆盖重复节点与失败状态修复

**目标：** 修复仙路湾 31 条订阅记录含 29 个唯一节点导致结果被拒绝的问题，并让无效结果及时结束任务。

**已确认方案：** 用户在只读根因报告后授权开始修复。保持不可变订阅快照，在覆盖任务下发、选取节点与发布计分时使用同一唯一节点标识去重；不同 URI 的同名节点保留。继续拒绝重复、遗漏、外来结果，不通过放松校验掩盖问题。确定性校验失败提交失败状态后再返回 HTTP 400，不能因抛异常回滚失败状态；采集器失败同样及时结束批次并保留原成绩。手动任务读取批次失败原因。

**技术：** TypeScript、MySQL、现有 Python 探针（接口下发去重，无需修改探针协议）。
