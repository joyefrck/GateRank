# News 加载优化

目标：保留现有 News 布局、SEO 和专题下架保护，减少首屏外部依赖、重复正文解析及图片传输。

已验证：生产首页 4 张图片共 157794 字节，HTML gzip 15276 字节；首字节约 1.3–1.6 秒。Google Fonts CSS 请求 20 秒超时。News 卡片仅取阅读时长却调用完整 Markdown 渲染。全站专题导航中间件主动覆盖 HTML 为 no-store，不在本次放开。

- 移除 News CSS 的 Google Fonts import，使用站内现有系统字体回退。
- NewsContentService 提供轻量阅读时长计算，和完整渲染共用嵌入内容预处理，卡片不再生成 HTML。
- 为已有本地新闻封面提供 320/640/960px WebP 变体，按 srcset/sizes 选择；原图 URL 保留为 fallback，第三方图片不代理。
- 变体仅允许新闻目录内普通图片文件及固定尺寸，缓存有界、失败回退原图；普通新闻图片使用一天缓存和条件验证，不影响工具文件。
- 验证：路由安全边界、变体尺寸/体积、卡片零正文渲染、News SSR 测试、类型检查和构建；Chrome 检查桌面和手机。

本次先完成本地实现和验证；生产耗时改善需上线后复测。

验证完成：45 项相关测试通过；server:typecheck、lint 和生产构建通过。Chrome 桌面与 390px 手机检查通过，图片正常，H2 结构保留，无横向溢出。生产首图样本原始 24394 字节，320/640/960px 变体分别为 3270/9112/14690 字节（减少 87%/63%/40%）。这些是本地变体测试结果，不代表已部署的生产加载时间。
