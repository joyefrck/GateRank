# Deal Card Copy Icon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move coupon copying from the card footer into an icon-only button immediately to the right of the coupon code.

**Architecture:** Keep the behavior inside the existing shared `DealCard`, so both the deals list and airport detail page update together. Reuse the current Clipboard API state, add a success check icon and accessible labels, and reduce the footer to navigation actions only.

**Tech Stack:** React, TypeScript, Tailwind CSS, lucide-react, Node test runner, Vite

---

- [ ] **Step 3: Implement the icon-only copy control**

In `src/pages/deals/DealCard.tsx`, import `Check`, render the coupon and button as one inline group, and remove the footer copy button:

```tsx
import { Check, Copy, ExternalLink, Sparkles } from 'lucide-react';

<DealField label="优惠码">
  <span className="inline-flex items-center gap-1.5">
    <span className="inline-flex h-7 items-center rounded-lg bg-blue-50 px-2.5 font-black text-blue-700">
      {deal.coupon_code}
    </span>
    <button
      type="button"
      onClick={() => void copyCoupon()}
      aria-label={copied ? '优惠码已复制' : '复制优惠码'}
      title={copied ? '优惠码已复制' : '复制优惠码'}
      className="inline-grid h-7 w-7 shrink-0 place-items-center rounded-lg border border-slate-200 bg-white text-slate-500 transition hover:border-blue-200 hover:bg-blue-50 hover:text-blue-700 focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-blue-500 focus-visible:ring-offset-2"
    >
      {copied ? <Check className="h-3.5 w-3.5 text-emerald-600" /> : <Copy className="h-3.5 w-3.5" />}
    </button>
  </span>
</DealField>
```

Change the footer grid to fit only its remaining actions:

```tsx
<div className="mt-4 grid grid-cols-[repeat(auto-fit,minmax(112px,1fr))] gap-2.5">
```

Delete the previous black copy `<button>` from that footer.
